# 权威赛题迁移与初赛压力测试设计

## 1. 结论

原有两组各 2400 例的随机测试能证明算法在既定生成模型上稳定，但大量样本共享相同的理想波形、噪声和量化假设，不能等价于大量独立失效模式。新增测试因此不再只增加随机数，而是分成两层：

1. **严格初赛门禁**：所有输入保持在本届初赛明示范围内，必须全部通过；
2. **赛事迁移挑战**：借用权威赛题中的失真、调制和信号分离思想，用于暴露算法余量；其中超出本届初赛承诺的输入不阻断提交，但必须报告失败。

实现入口为 `tools/competition_stress_suite.py`，固定随机种子为 `20260919`，完整逐例结果在 `tests/results/competition_stress_report.json`。

## 3. 严格初赛门禁如何变难

严格门禁共 384 例，四类波形各 96 例。每例都经 `waveform_analyze_frame()` 进入与采集侧相同的正式接口，而不是绕过元数据调用内部函数。

| 维度 | 覆盖方式 | 它会击穿的简单算法 |
| --- | --- | --- |
| 频率 | 100、400 Hz 端点；100.137、137.173、199.951、250.25、333.333、399.863 Hz 等非整周期点；其余随机点 | 只取 FFT 最大 bin、只统计一两个交越、整数周期折叠 |
| 噪声 | 0%、5%、10%、15%、20% Vpp；白高斯、截止约 5.25 倍基频的有色高斯、高频高斯三类 | 固定阈值交越、只针对白噪声调参的滤波器 |
| 幅值 | 96、160、640、1800、3000 ADC counts Vpp | 极值 Vpp、低幅信号下不稳的归一化和相关计算 |
| 直流位置 | 靠近低端、靠近高端、量程中点、随机位置，同时保留防削顶余量 | 把样本均值误当上下电平中点、依赖固定 ADC 中点 |
| 方波 | 20%、21%、37%、50%、63%、79%、80% 占空比；上升/下降沿独立覆盖 0%–10% 周期 | 只支持 50% 方波、对称边沿或单阈值占空比算法 |
| 采样时钟 | 19.760、19.997、20.000、20.240 kS/s，并通过元数据给出真实值 | 把 20 kS/s 写死、忽略采样时钟标定 |
| 标定参数 | VREF 3.00–3.36 V，前端增益 0.8–1.5，均使用整数单位接口 | 只在 3.3 V、单位增益下看似正确的电压换算 |
| ADC 非理想 | 0、0.25、0.5 LSB 的确定性 INL 扰动和 12 bit 量化 | 只用浮点理想样本验证的算法 |
| 起始相位 | 全范围确定性散布 | 依赖采样窗口从峰值或边沿开始的模板 |

门禁阈值为：分类全对、状态全为 `OK`、频率误差不超过 0.50%、Vpp 误差不超过 8.0%、方波占空比误差不超过 2.0 个百分点。这比“平均误差”更严格，任意一例失败都会令脚本返回非零。

### 为什么这些题会用到培训中的算法

- 非整周期频率迫使算法处理谱泄漏或使用插值、回归，不能只读 FFT 栅格；
- 20% 有色高斯噪声会让单阈值交越抖动，需要滞回、周期证据融合与多周期统计；
- 低幅值和近量程边界使极值 Vpp 明显有偏，需要稳健折叠和全周期拟合；
- 20%/80% 占空比与独立缓边沿要求分类模型显式搜索占空比、边沿，并在 50% 电平处插值；
- 正弦与三角在强噪声下非常接近，需要利用完整周期形态，而不是少数斜率阈值；
- 校准元数据变化检查了算法与采集协议是否真的解耦。

## 4. 赛事迁移挑战

挑战组共 96 例，保持四类输出标签和 100–400 Hz，但故意加入本届初赛没有承诺的成分，因此默认只诊断、不阻断：

| 挑战 | 强度 | 目的 | 是否属于初赛硬承诺 |
| --- | ---: | --- | --- |
| 顶部/底部/双向失真 | 6%–8% 归一化削平 | 检查轻微非线性是否把正弦误判成方波 | 否 |
| 交越失真 | 5% 死区 | 检查奇次谐波增加后的分类与 Vpp | 否 |
| 二、三次谐波 | 4%、6% | 检查谐波污染下的基频和类别 | 否 |
| 慢幅度变化 | 6%、13 Hz | 检查周期估计是否跟随包络而漂移 | 否，参数不再完全稳定 |
| 非整数倍相干干扰 | 8%、1.73 倍基频 | 检查窄带分量是否同时欺骗周期估计和模板 | 否，不是高斯噪声 |
| 五次谐波干扰 | 8% | 检查带内相干谐波对形态的影响 | 否，不是高斯噪声 |

挑战阈值放宽为频率 1.0%、Vpp 12.0%、占空比 3.0 个百分点。可在需要把挑战组升级为硬门禁时运行：

```bash
python3 -B tools/competition_stress_suite.py \
  --library tests/waveform_analyzer_host.so \
  --json tests/results/competition_stress_report.json \
  --require-challenge
```

## 5. 当前确定性结果

| 组别 | 通过 | 分类正确 | 最坏频率误差 | 最坏 Vpp 误差 | 最坏占空比误差 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 严格初赛门禁 | 384/384 | 384/384 | 0.0355% | 4.364% | 0.629 pp |
| 赛事迁移挑战 | 95/96 | 95/96 | 0.0479%（通过样本） | 9.972%（通过样本） | 0.617 pp |

唯一挑战失败为：399.863 Hz、80% 占空比、上升/下降沿各为 6% 周期的方波，幅度仅 800 ADC counts，直流位置靠近 ADC 低端，并叠加 10% 白高斯噪声和额外 8% 的 1.73 倍频相干干扰。粗周期被干扰诱导到约四倍周期，后续模型证据不足，算法返回 `CLASSIFICATION_AMBIGUOUS`，而不是错误地输出另一类别。它说明当前安全失败机制有效，也说明若决赛出现非高斯相干干扰，需要增强基波/倍周期消歧、增加局部谐波或残差证据，或延长采样后复测。

## 6. 怎么运行和看结果

完整回归：

```bash
bash tests/run_all_checks.sh
```

只跑 C 核心与赛事化压力测试：

```bash
bash tests/run_host_tests.sh
```

报告中每例都保存：输入参数、来源母题、干扰类型、状态、类别、三个误差、模型得分/余量和折叠周期数。失败时优先看 `status`：

- `CLASSIFICATION_AMBIGUOUS` 表示算法拒绝在证据不足时猜测；
- `ADC_*_CLIPPED` 表示模拟链路已经丢失信息；
- `PERIOD_NOT_FOUND` 表示周期证据不足；
- `OK` 但误差超限才是真正的参数估计偏差。

## 7. 仍不能替代的实测

仿真仍无法忠实覆盖信号发生器输出阻抗、连接线耦合、运放压摆率、RC 幅相响应、ADC 采样保持建立时间、DMA 丢样和电源纹波。赛前必须把同一测试矩阵落实为信号源/示波器/板卡三方实测，至少记录每类 100、250、400 Hz，低/中/高 Vpp，方波 20%/50%/80% 占空比和 0%/10% 边沿的原始 ADC 数组，随后用本脚本的同一误差口径验收。
