# Vpp 预处理离线对照（2026-10-24）

结论：可以用保留波形边沿的孤立异常点降权来改善抗毛刺能力，但当前数据没有显示它能解决主要 Vpp 偏差。不要直接对原始波形做滑动平均或中值平滑后沿用原幅值算法。

后续用户曾指定接入 3 点中值滤波，随后明确要求移除，并进一步撤销 50 点校准、恢复原校准，见 [当前输出规则](vpp-output-policy.md)。本文件保留此前的离线对照结果，离线对照工具中的中值滤波不进入正式算法。

## 本次数据与边界

对照使用 234 帧真实 ADC 归档：正在进行的 50 点校准中已完整保存的 180 帧，以及此前的 54 帧正弦、方波、三角波实测。帧清单在开始时冻结，没有读入之后追加的记录；每帧校验有效状态、载荷长度和 FNV-1a，并记录 SHA-256。

本次不占用 USB 信号源或 COM15，没有修改校准参考、候选参数、正式幅值路径和原始 ADC 字节。关联聊天继续执行它的 50 点校准。

输出在 `data/vpp-preprocessing-20261024/`：`summary.json`、`frames.jsonl`、`comparison.png`、`example.json`。

## 比较结果

每种方法都使用同一个谐波基波最小二乘诊断器，区别仅在于预处理。此处是滤波对幅值的影响分析，**不是正式测量算法回放，也不是独立电压准度认证**。

| 方法 | 234 帧 Vpp 变化的中值 | 最大绝对变化 |
| --- | --- | --- |
| 孤立异常点降权 | 约 0% | 0.0121% |
| 3 点中值滤波 | −0.0219% | 0.2320% |
| 5 点滑动平均 | −0.4395% | 0.9619% |

226 帧含满足保守规则的孤立创新点，每帧降权点数的中值为 16/8192。三角波在中值滤波后变化最大达到约 −0.232%；305 Hz、20 kS/s 附近的 5 点滑动平均，使基波幅值下降约 0.916%。这不是噪声被消除后的准度提升，而是滤波器改变了信号增益。

共有 53 组有至少 3 帧可比较重复性；降权后 28 组的标准差下降，25 组没有改善。组内相对标准差的中值从约 0.02316% 变为 0.02251%。这点改善不能解释或消除之前约 0.2% 的整体偏差。

ADC 数据中的异常点可能来自信号源、接线、模拟通路、采样时序或 ADC，单路数据无法据此定位到信号发生器。示波器直接读取原始最大值减最小值，也会把毛刺和噪声算入峰峰值；应与平均波形或拟合幅值区分。

## 原型与后续使用

`tools/vpp_preprocessing.py` 提供独立原型：

1. 以实测频率建立周期谐波模型，用 MAD 估计非边沿残差尺度。
2. 只对大于 6 倍残差尺度、连续长度不超过 2 点的孤立异常降权。
3. 保护方波边沿、三角波尖点和锯齿波跳变；保留相同相位反复出现的结构，避免将真实过冲、纹波当成随机毛刺删除。
4. 异常过密或周期数不足时不处理。原始采样不改写，权重必须同时作用于观测和待拟合模型。

原型没有接入正式算法，因为实测改善不足以证明应改变当前校准和测量定义。后续若接入，必须让校准参考与普通测量使用同一处理，并保持原始饱和/非法 ADC 码检查先执行。不能用去毛刺把采集错误隐藏掉。

时序抖动与脉冲毛刺应分别处理：独立周期相位对齐、周期一致性检查适合时序抖动；周期同步平均适合不相干噪声。现有谐波拟合本身已经具有跨周期积分作用，额外平滑不能自动创造新的信息。同相位重复的干扰以及电压校准误差仍需单独处理。

复现：

```powershell
python tools/compare_vpp_preprocessing.py --session data/20261024T133356.799663Z-ce766887 --session data/vpp-baseline-20261024/20261024T122033.157535Z-783d2f86 --session data/vpp-span-diagnosis-20261024/20261024T122818.484149Z-0eb6bed9 --output data/vpp-preprocessing-new-output
python -m pytest -q tests/test_vpp_preprocessing.py
```

如果校准会话仍在追加，新运行的帧数量会比本报告多；本报告的精确 234 帧由 `frames.jsonl` 中的路径和哈希确定。

专项测试 4 项、8 个子测试通过，覆盖注入脉冲抑制、干净波形尖点/边沿保留、高斯噪声不误删和非法输入拒绝。未进行新一轮 USB 实测或 296 项正式算法回放。
