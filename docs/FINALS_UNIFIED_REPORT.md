# 决赛统一求解器 4.0：实现、验证与边界

本版已经实现、接入并运行独立的多起点广义变量投影最小二乘。R / RO / RT 不使用旧 C 分类器或其初值，全部采样点进入分类与测量。**“所有输出达到百万分之一”没有达成，也不能依据当前输入条件保证。** 本文结果是软件证据；没有重新烧录板卡、采集新的实板数据或重新标定。

## 手册核对

依据工程内原始赛事手册第 3 页：决赛包含较弱、较强干扰两组，每组四类基础波形加随机重复类型；噪声预生成后循环回放；单样本总处理上限 15 秒；强干扰允许重测一次并以重测结果提交；最终频率、峰峰值、偏置、方波 duty、噪声和带宽范围需在赛前一周公布。当前附件不含这份最终范围公告。初赛的 100–400 Hz、20%–80% duty 不能宣称为已确定的决赛范围。

手册要求单片机输出结果。当前工程仍由电脑计算、电脑输出 RESULT；未找到明确允许这种架构的条款。没有完成 MCU 移植，不能称作已经确认可参赛的单片机独立实现。电脑参与是否被许可，需要赛事方明确确认。

## 最终算法

对每个候选频率和每种波形，统一最小化白化后的采样残差。模型中的 DC 和幅值线性消去；非线性变量为频率、相位，以及方波的 duty、上升宽度、下降宽度。解析 Jacobian 含幅值消去后的导数项，已与中心差分核对。类别用带参数数量惩罚的残差评分比较；评分不是可信概率。

每个频率起点先用数据检查周期相干性和高阶谐波能量：满足低带宽相干条件时，对低阶子空间使用较小权重；其他记录保持单位权重。每个起点的白化算子在其优化期间固定，各波形共享该算子。默认低阶权重 0.01、阶数 5、相干残差阈值 0.06、高阶能量阈值 0.04。这些是工程先验，未知带宽或其他噪声分布可能违反先验，不给出准确度保证。未将任意残差谐波直接算入源峰峰值。

下降锯齿的重置确定离散周期标号，投影拟合坡度和跳变高度，并用相邻采样之间的重置时间区间约束频率。修复了帧首/帧尾重置遗漏，以及含噪坡度比与已观察重置时间不一致的问题。方波反相时正确转换高电平 duty；duty 搜索端点的分位数初始化也有独立回归。极短边沿、锁相阶跃不能据小残差推断亚采样边沿可辨识。

默认频率区间为至少四周期/帧到 fs/12，可通过 CLI 指定；这描述实现的默认搜索范围，不是决赛官方范围。多起点、有限迭代及工程噪声先验均不构成全局最优或误差上界证明。默认每帧求解预算 5 秒，R 总预算 15 秒，默认一帧；允许增加起点、预算或分别拟合多帧。没有跨串口间隙拼接采样。

时间成本包括 FFT、每起点的低维 QR / 最小二乘、各模板投影迭代和重置时间约束。数据工作区留在电脑，不能直接搬进 MCU SRAM。核心仅依赖 NumPy、SciPy 和 threadpoolctl。

## 两种“百万分之一”定义

本报告同时保存以下定义，避免把单位与相对精度混淆：

1. 相对：|f估/f真−1|<10⁻⁶，|Vpp估/Vpp真−1|<10⁻⁶，方波 |D估/D真−1|<10⁻⁶。非方波 duty 固定 0。全部字段达到者为 2/221。
2. 绝对：频率误差 <10⁻⁶ Hz，电压误差 <10⁻⁶ V，输出 duty 百分数误差 <10⁻⁶ 个百分点。全部字段达到者为 0/221。

duty 的“fraction ppm”与“relative ppm”是两个不同列。已从逐项结果重算、再由格式化输出反算核对。数据在 CSV / JSON 中保留，不能用输出小数位或低残差代替准确度。

## 为什么无法保证全部 1 ppm

循环噪声的一部分可能位于基波，同相位平均不能分开这部分噪声和真实幅值。构造两个源幅值不同、ADC 数组完全一致的世界，是非唯一性的直接见证。`counterexamples.json` 保存以下 Python 验证：源 Vpp 1.5 与 1.500015 V，在一个世界加入对应基波扰动后 ADC 完全相同；锁相方波 duty 0.2 与 0.201 的样本完全相同；信号频率和真实采样率按相同比例变化，采样相位完全一致。

基波扰动示例不是宣称赛事噪声为纯正弦。对有限个预生成高斯样本，重叠的噪声似然同样不能给出对所有实现的确定准确度保证；把一个未知基波分量归于信号还是噪声，需要额外独立信息或概率假设。校准的时钟、增益、参考电压和 ADC INL 也是独立误差来源。12 位 ADC 的单点量化间隔不是多点拟合精度的硬下限，但锁相量化和系统误差不能因为拟合迭代更多就保证消失。

只在模型正确、参数可辨识、充分带宽和信噪比、独立/已知噪声以及足够可溯源的时间与电压校准条件下，才适合给条件性精度结论。当前软件结果不满足“所有输出 1 ppm”的要求。

## 时限与使用

8192 点、20 kS/s、115200 8-N-1 的理论 ADC 采样时间 0.409600 秒，原始 payload 的理论发送时间 1.422222 秒，合计 1.831822 秒。加本机观测软件最大耗时为 3.429760 秒；未计串口头尾、驱动、调度、存档及恢复，不能等价于实机 15 秒验收。R 在总期限之后不提交部分输出。

```powershell
python -m pip install -r requirements.txt
python server.py R --port COM6
python server.py R --port COM6 --solver-starts 8 --solver-seconds 10
python server.py RT
python -m tools.finals_matrix --compare
python -m unittest discover -s tests -p "test*.py" -v
```

正式范围公布后再指定 `--solver-fmin` / `--solver-fmax`。电脑算法许可、板卡端到端耗时、实际时基与电压校准仍待实测确认。原校准文件和采集固件未修改，没有新增实板固件二进制。

最终源码：`tools/unified_solver.py`；接入：`tools/host_waveform.py`、`tools/waveform_server.py`、`tools/precision_batch.py`；矩阵：`tools/finals_matrix.py`；原 3.0 工程说明保留为历史材料。当前结论以本文和最终验证目录为准。
