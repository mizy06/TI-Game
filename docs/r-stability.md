# R 锯齿波跨帧回退修复（2026-10-24）

用户会话 `data/20261024T141433.610209Z-266f68db/` 中的 4 次 `Out of range float values are not JSON compliant: inf` 已复现。对应三帧请求从 UART 编号 55、85、88、94 开始。

这些请求的单帧分析均有效。可选的锯齿波跨帧幅值拟合检测到跳变位置不可靠，抛出 `unreliable saw reset lattice for amplitude`。汇总逻辑原本会回退到有效单帧 Vpp 的中位数，却把无法计算的跨帧差异记录为 `inf`；严格 JSON 归档因此失败。

修复后，缺失或非法的跨帧估计使用 `null` 表示不可比较的诊断量，保留模型拒绝原因，并正常输出有效单帧的汇总值。没有有效估计时不会伪造结果。跨帧锯齿波估计中的非正值及非有限幅值会明确拒绝，避免继续构造含 `inf` 的诊断记录。JSON 仍使用 `allow_nan=False`。

原校准、Vpp 最终乘以 0.9985 和四舍五入两位小数的输出规则保持原设置。

验证：

- 同一进程池连续回放 5 次完整三帧 R，共 15 帧，包含上述 4 次原失败请求和相邻成功请求；5/5 成功输出和归档，单次约 1.19–1.73 秒。
- 原始采样字节、元数据及校验和均校验；15 个回放记录全部通过严格 JSON 解析。
- 43 项回归测试、59 个子测试通过，覆盖无效跨帧值、拒绝后下一次 R 的恢复、单帧归档、并行分析和输出规则。

回放程序、结果与记录位于 `data/vpp-r-stability-20261024/`。本次未占用 COM15 或操作信号发生器。

重启运行中的 `server.py`，确保主进程和 3 个分析进程加载新代码。
