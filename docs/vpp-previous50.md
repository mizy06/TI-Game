# previous 方式 50 点校准接入（2026-10-24）

历史记录：下述 previous 方式 50 点接入已按用户后续要求撤销。当前已恢复实验前原校准，并在最终输出时统一扣除 0.15%、四舍五入保留两位小数，见 [当前输出规则](vpp-output-policy.md)。以下内容记录撤销前的实现及验收，不代表当前默认配置。

## 当前计算和参数

局部电压换算沿用 `data/20261024T123915.281073Z-68340560/rs-1792845567833731500/amplitude_calibration.json` 的 `local_transfer`，方法为 `independent_AC_phase_referenced_ADC_code_average`。50 点幅值/偏置响应由后续会话的 200 帧未滤波 ADC 数据重新计算，共 10 个幅值、5 个偏置，每点 4 帧。原始数据位于 `data/20261024T133356.799663Z-ce766887/rs-1792848844680145900/`。

单帧频谱估计、含噪声回退和跨帧联合估计均使用未滤波的 ADC 数据。电压换算后计算 Vpp，再进行一次幅值/偏置响应逆校正。频率、占空比、DC 和采样时间校准保持原来的处理。原始 ADC 字节及其有效性、饱和检查保持不变。

移除滤波时重新计算了整张响应表，没有沿用此前带中值滤波的响应补偿。正式路径不再支持旧的滤波参数；误载旧滤波参数会要求从未滤波参考重建，避免静默混用。离线比较工具仍保留滤波选项，供历史分析使用。

后续 RS 使用 previous 的局部换算步骤，再采集 50 点幅值/偏置响应及 10 点独立验收。不会调用 50 点直接曲线拟合函数。自动发布仍要求独立验收全部通过；本次按用户明确要求手动启用，验收状态如实保存在参数来源中。

## 独立归档回放

40 帧、10 个参考点仅用于验证，没有进入响应表计算。使用正式 `host_waveform.analyze` 路径及现有时间/DC 校准重放，结果相对信号源设置值：

| 设置 Vpp | 偏置 1.45 V：相对误差 | 偏置 1.75 V：相对误差 |
| --- | --- | --- |
| 0.87 V | +0.16514% | +0.17154% |
| 1.07 V | −0.07425% | −0.08990% |
| 1.23 V | −0.01720% | −0.03767% |
| 1.47 V | −0.00238% | −0.01627% |
| 1.57 V | −0.15702% | −0.11061% |

按 0.1% 门限通过 6/10，最差 0.17154%，绝对误差中位数 0.08207%。没有宣称达到 0.1% 准度目标，也没有进行新的 USB 全矩阵测试。

当前参数为工程根目录的 `algorithm_parameters.json`，SHA 校验和参数重载已验证。接入记录、逐帧输出及移除滤波前的备份在 `data/vpp-previous50-raw-20261024/`。更早的原始参数备份在 `data/vpp-previous50-median3-20261024/parameters-before.json`；带滤波的历史结果保留在该目录，当前不使用。

运行中的服务器需要重启以确保加载全部新代码：

```powershell
python server.py --port COM15 --verbose --ro-resource "USB0::0xF4EC::0x1101::SDG6XFCQ900848::INSTR"
```

重新构建和回放的方法（输出目录必须尚不存在）：

```powershell
python tools/apply_previous_vpp_calibration.py --reference-report data/20261024T133356.799663Z-ce766887/rs-1792848844680145900 --local-report data/20261024T123915.281073Z-68340560/rs-1792845567833731500 --output data/previous50-recheck
```

默认只生成候选及回放记录；显式 `--activate` 才写入参数，并保留实际独立验收状态。Vpp 参考设置只进入校准和验证工具，不进入普通测量算法。
