# 锯齿波幅值合并修复（2026-10-25）

本次扫描里，40% 噪声下的 `fallback=True` 主要发生在三帧幅值合并，
各帧的主求解器已成功，`fallback_frames` 为空。旧检测器将帧开头的
噪声跳变识别为复位，随后因相邻边沿间距不满足一个周期而拒绝合并。
另有情况是谐波幅值受未隔离的背景噪声影响，与独立帧结果不一致。

现在按已测频率形成的周期格点筛选真实观测边沿，并检查周期完整性。
没有插入复位边沿；中间缺失复位仍拒绝估计。检测支持两种锯齿方向。

对于没有频谱隔离的背景，在剔除复位附近两点的实际斜坡采样上做联合
线性回归，各帧保留各自时间原点和直流项。有隔离证据时使用谐波投影。
共享幅值按各帧回归信息量合并，替代原来的三帧谐波幅值中位数。
幅值一致性门限保持原值；不使用扫描标签或发生器设定值选择估计。

保存的 15 组、45 帧现场数据离线回放中，幅值合并回退由 5 组降至 1 组。
其中 7 组 40% 噪声均通过；保留的 1.4 V、10% 噪声组仍未通过一致性检查。
这些回放均在 100 Hz，不代表整个频率和幅值范围已验证，也不认证 0.1% 绝对精度。

回放输入、脚本和结果在 `data/vpp-saw-repair-20261025/`。相关回归检查覆盖
首周期假边沿、中间复位缺失、两个方向、多相位、强噪声与多帧拒绝回退。

扫描日志现在另行打印回退阶段：`model_fit`、`frame_selection` 或
`joint_amplitude`。当前运行进程需要重启才会加载新算法；使用新输出目录
避免混合算法版本，原始数据保留。
