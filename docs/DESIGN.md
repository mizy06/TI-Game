# 方案设计、取舍与验证

## 1. 赛事约束转化

初赛约束直接转化为以下工程指标：

| 手册约束 | 工程处理 |
| --- | --- |
| MSPM0G3507 | 使用片内 ADC12、TIMA0、UART0、GPIO |
| 100–400 Hz | 20 kHz 采样，每周期 50–200 点 |
| 四类波形 | 四个解析模板，不依赖训练集 |
| 下降锯齿 | 锯齿模板固定为下降斜坡和上跳复位 |
| 方波边沿 ≤ 10% 周期 | 仅使用很轻的 1-2-1 FIR，避免把边沿滤圆 |
| 方波占空比 20%–80% | 方波模板按实测下降穿越位置动态生成 |
| 噪声 Vpp ≤ 信号 Vpp 的 20% | 滞回穿越、异常周期剔除、多周期相位平均 |
| 输入全程无负压 | 仍要求硬件保证不高于 VDDA；软件检查上端削顶 |
| 单样本 ≤ 10 s | 采集约 0.205 s，算法规模固定且无迭代训练 |
| 输出类别、频率、Vpp、方波占空比 | 单行结构化 UART 输出，便于现场抄录和脚本解析 |

手册没有给出初赛的幅度、偏置和参数误差阈值，因此设计必须避免依赖固定电压阈值，并将 VDDA 校准项暴露为宏。

## 2. 候选方案

### 方案 A：纯时域特征决策树

特征包括过零次数、斜率方差、二阶差分、平台样本比例、峰度和偏度。

优点：运算少、实时性强、实现简单。缺点：阈值较多；频率、采样相位、方波边沿和滤波强度会共同改变斜率特征；正弦和三角波在噪声下容易逼近阈值边界。适合作为快速预分类，不适合作为唯一判据。

### 方案 B：频域谐波比 / Goertzel

先估计基频，再比较 1、2、3、5 次谐波幅度：正弦以基波为主，方波奇次谐波强，三角波奇次谐波按平方衰减，锯齿波含连续整数次谐波。

优点：理论解释清晰，对随机时域噪声较稳健。缺点：非整数周期截断会造成谱泄漏；基频误差直接污染谐波幅度；20%/80% 占空比方波会出现偶次谐波并改变所有比值；Cortex-M0+ 无 FPU，实现复杂度和调参成本较高。

### 方案 C：单周期重采样 + 模板匹配

估计一个周期，将其归一化为固定长度，再和四种模板比较。

优点：不需要很多人工阈值，四类波形的完整形态都参与判断。缺点：只取一个周期时，20% 噪声会直接进入模板误差；一次误检边沿就可能导致整个周期错位。

### 方案 D：稳健周期检测 + 多周期相位折叠 + 模板相关（采用）

在方案 C 基础上，使用滞回上升穿越得到几十个周期；以周期中位数剔除异常间隔；每个有效周期重采样到 128 个相位格并求平均；最终做去均值相关匹配。

| 评价维度 | A 时域树 | B 谐波比 | C 单周期模板 | D 多周期模板 |
| --- | ---: | ---: | ---: | ---: |
| 对随机高频噪声 | 中 | 高 | 中 | 高 |
| 对任意直流偏置 | 高 | 高 | 高 | 高 |
| 对方波占空比变化 | 中 | 中 | 高 | 高 |
| 对频率非整周期 | 高 | 中 | 高 | 高 |
| 正弦/三角分离余量 | 中 | 高 | 高 | 高 |
| M0+ 实现复杂度 | 低 | 高 | 中 | 中 |
| 失效可诊断性 | 中 | 中 | 中 | 高 |

方案 D 不依赖训练数据、不依赖绝对幅值，并且把 204.8 ms 窗口内 20–80 个周期用于相干平均，是当前规则下最稳妥的初赛实现。

## 3. 实现流程

1. TIMA0 每 50 µs发布一个事件，ADC0 每事件转换一次；
2. ADC 中断仅搬运 4096 个 12 位样本，满缓冲后立即停表；
3. 对样本做 1-2-1 FIR；
4. 用 256 桶直方图求 5% 和 95% 分位，得到不依赖偏置的中心和滞回宽度；
5. 检测低阈值到高阈值的上升穿越，并在线性插值到 Q8 子采样位置；
6. 以周期中位数为基准，仅保留 75%–125% 范围内的间隔；
7. 每个有效周期在 128 个相位格中心重采样并求平均；
8. 从平均周期估计方波候选下降穿越位置；
9. 对四个模板计算去均值相关系数平方，最高者为类别；
10. 由所有有效周期间隔计算频率，由平均周期极差计算 Vpp；下降锯齿补偿相位格中心采样少掉的 1/128 幅度。

## 4. 主要失效场景与对策

| 场景 | 风险 | 当前对策 | 现场动作 |
| --- | --- | --- | --- |
| PA25 高于 VDDA | ADC 削顶，类别和 Vpp 均失真 | 统计 4092–4095 码数量并报错 | 降低幅度/偏置或接前端 |
| 信号幅度过小 | 噪声主导穿越 | 5%–95% 跨度小于 48 counts 报错 | 提高幅度或检查地线 |
| 未共地/接触不良 | 周期丢失或随机跳变 | 滞回、异常周期剔除、周期数输出 | 检查 BNC 地和杜邦线 |
| 触发时相位任意 | 窗口首尾不完整 | 只折叠相邻完整上升穿越之间的周期 | 无需人工对相位 |
| 100 Hz 最少周期数 | 平均次数降低 | 仍有约 20 个完整周期 | 保持 4096 点，不缩短窗口 |
| 400 Hz 每周期仅 50 点 | 边沿采样有限 | Q8 穿越插值和 128 相位重采样 | 不提高 FIR 阶数 |
| 20% 或 80% 方波 | 平台样本不平衡 | 5%/95% 分位仍覆盖两平台；动态占空比模板 | 无需改阈值 |
| 正弦与三角波相似 | 仅斜率阈值余量小 | 完整相位模板相关，所有 128 点参与 | 查看 `margin_pct` |
| 高频噪声触发假边沿 | 频率翻倍 | 双阈值滞回 + 最小间隔 + 周期中位数 | 必要时使用可选 RC |
| VDDA 偏离 3.3 V | Vpp 比例误差 | 单一校准宏 | 赛前实测并修改宏 |
| 系统时钟误差 | 频率比例误差 | 单一采样率宏 | 用标准信号做一点校准 |
| 串口引脚接反 | 无输出/无法触发 | 同时支持 PB13 按键触发 | 交换 TX/RX 并共地 |

## 5. 仿真验证

`tests/host_test.c.txt` 用确定性伪随机序列生成 2400 个样本：

- 每类 600 组；
- 频率均匀覆盖 100–400 Hz，并重复测试 100、101、399、400 Hz；
- 方波占空比覆盖 20%–80%，并重复测试 20%、21%、50%、79%、80%；
- Vpp 覆盖约 80–3240 ADC counts；
- 直流偏置在不削顶的整个可行范围随机变化；
- 奇数组叠加 5 个频率为基频约 5–18 倍的带限干扰分量，偶数组叠加白色高斯噪声；两类噪声 Vpp 均随机覆盖信号 Vpp 的 0–20%；
- 初始相位随机。

当前回归结果：

```text
cases=2400 class_fail=0 measurement_fail=0 contract_fail=0 worst_freq=0.1468% worst_vpp=6.932% worst_duty=1.666 percentage-point
```

Vpp 的最坏值来自“按规则上限叠加确定性带限干扰”而非 ADC 量化本身。相位折叠显著减小随机/非相干噪声；若赛方噪声恰好与基频整数倍严格相干，任何仅观察输出波形的软件方法都无法完全区分它和原波形的谐波，这也是现场需要保留轻度模拟滤波选项的原因。

## 6. 为什么没有修改 SysConfig

`empty.syscfg` 文件头明确要求 AI 不直接编辑，并要求使用 SysConfig 工具进行有校验的修改。本环境没有可用的 SysConfig 配置接口，因此遵从该边界：

- 不修改 `empty.syscfg`；
- 不修改 `Debug/ti_msp_dl_config.c/.h` 等生成文件；
- 复用原工程已经连通的 TIMA0 → ADC0 事件、20 kHz 定时、PA25 ADC、PA0/PA1 UART 和 PB13 GPIO；
- 在应用初始化后调用 DriverLib 关闭原先的 UART loopback，并给 PB13 配置上拉和施密特输入。

这样既避免破坏受保护配置源，也保证重新生成代码后算法和应用逻辑不丢失。

## 7. 后续决赛增强接口

当前算法已经为 30%–50% 噪声保留了结构基础，但初赛包不声称覆盖尚未公布的决赛参数。若进入决赛，建议按最终公布范围增加：

- DMA 双缓冲，降低 20 kHz ADC 中断负担；
- 周期折叠前的自适应带通或 Savitzky-Golay 滤波；
- 模板分数与谐波比的双判据融合；
- Vpp 的类别相关稳健估计和 VDDA/时钟两点校准；
- 强噪声下对多次采集结果做一致性投票。
