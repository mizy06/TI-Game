# 算法分支设计说明

## 1. 目标

本分支面向 2026 TI 杯赛道一：在 MSPM0G3507 上处理外设采集的模拟信号数组，识别 sine、square、triangle、下降 sawtooth，并尽可能精确地测量频率、Vpp 和方波占空比。

算法实现遵循三个原则：

1. 误差来源可分解：算法估计误差、采样时钟误差、电压参考误差和前端增益误差分别处理；
2. 不依赖固定电压阈值或未经验证的训练集；
3. 计算量和静态内存受控，适合 80 MHz Cortex-M0+ 与 32 KiB SRAM。

培训材料的逐项评估、替代算法和完整取舍见 [算法研读与取舍](ALGORITHM_RESEARCH_AND_DECISIONS.md)，采集侧 ABI 见 [采集-算法接口协议](ACQUISITION_ALGORITHM_INTERFACE.md)。

## 2. 数据流

| 阶段 | 实现 | 输出 |
| --- | --- | --- |
| 帧校验 | 指针、长度、采样率、参考电压、增益、连续性标志 | 明确状态码 |
| 输入质量 | ADC 码范围、双端削顶、5%/95% 直方图分位 | 稳健中心与幅度 |
| 轻滤波 | 正确的对称 1-2-1 FIR，仅用于周期检测 | 降低高频交越抖动 |
| 粗周期 | 98–402 Hz 范围 AMDF，最早可信局部极小 | 避免倍周期 |
| 细周期 | 双阈值交越、Q12 插值、漏交越恢复、线性回归 | 精细周期与频率 |
| 相位折叠 | 原始点线性插值到 128 相位格；逐格去一对极值后平均 | 低噪典型周期 |
| 占空比候选 | 稳健高低电平中点、循环双边沿插值 | duty ppm |
| 分类 | 全相位搜索；方波同时搜索独立上升/下降边沿宽度 | 类型、分数、余量 |
| Vpp | 最佳类别模板的仿射最小二乘幅度 | ADC counts Q16 |
| 标定换算 | 参考电压与前端增益元数据 | 输入端 µV |

## 3. 关键实现决定

### 3.1 不把去噪和参数估计混为一谈

滤波后的数组只服务于周期搜索和交越。折叠、分类、Vpp 和占空比都从原始 ADC 数组重采样，避免滤波器的通带衰减和边沿钝化进入最终参数。

### 3.2 频率采用双证据

AMDF 覆盖完整波形形状，对正弦和非正弦都有效，但 P、2P、3P 都可能形成极小值。实现选择最早可信局部极小，并用交越周期中位数检查基波/倍周期关系。交越回归则把几十个周期的相位信息共同用于斜率估计，显著降低单次交越抖动。

### 3.3 分类是带未知参数的模型选择

每类都搜索全部 128 个循环相位。方波还搜索：

- 实测占空比；
- 0、2.5%、5%、7.5%、10% 上升边沿；
- 0、2.5%、5%、7.5%、10% 下降边沿。

评分为去均值仿射拟合的相关系数平方。最高类别分数低于门限或领先余量不足时拒识，避免把不确定结果包装成“成功”。

### 3.4 类别相关 Vpp

最佳模板保留后，对全部 128 个折叠点拟合偏置和幅度。相较折叠极差，这会使用整个波形的数据，并减少噪声极值偏差；相较固定分位数，它不会给四种分布形状引入不同的理论偏差。

### 3.5 校准值属于输入，不属于魔法常数

waveform_frame_t 显式携带：

- sample_rate_millihz；
- adc_reference_microvolts；
- frontend_gain_ppm；
- sequence 和校准标志。

频率和电压比例误差由采集侧标定后进入同一计算链。未标定时通过 quality_flags 明示，不虚报精度。

## 4. 复杂度与内存

固定 20 kS/s、4096 点时：

- 原始 ADC 缓冲：8192 B，由 empty.c 持有；
- 算法静态 BSS：约 14112 B；
- 合计约 22.3 KiB，未计少量应用全局量和栈；
- AMDF 约 150 个延迟、隔点比较约 30 万次；
- 模型搜索少于 100 万个相位点级整数操作；
- 无堆分配、无递归、主路径无浮点和三角函数。

主机时间不能替代板上最坏时间测试。当前只可确认算法规模有界，且远低于比赛 10/15 s 上限的设计预算；最终必须在 Release/O2 固件上用 GPIO 或周期计数器测量。

## 5. 失败与质量策略

致命失败使用 status：

- 空指针/坏元数据/样本不足；
- ADC 数字码非法；
- 高低端削顶；
- 信号太小；
- 无可靠周期、频率越界；
- 分类分数或类别余量不足。

非致命风险使用 quality_flags：

- 采样时钟未校准；
- 参考电压未校准；
- 有效周期少；
- 类别余量偏低。

调用者不得在 status 非 OK 时继续使用频率/Vpp/占空比字段。

运行：

    bash tests/run_all_checks.sh

确定性结果：

| 组别 | 样本数 | 分类失败 | 测量阈值失败 | 最坏频率 | 最坏 Vpp | 最坏占空比 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 初赛 0–20% 噪声 | 2400 | 0 | 0 | 0.0678% | 4.233% | 1.666 pp |
| 强干扰 20–50% 噪声 | 2400 | 0 | 0 | 0.2317% | 5.217% | 0.524 pp |

强干扰测试还随机覆盖：

- 18–22 kS/s 实际采样率；
- 1.5–3 倍信号频率的一阶低通高斯噪声带宽；
- 方波独立 0–10% 上升/下降边沿；
- 20%–80% 占空比；
- 参考电压和前端增益元数据。

另有 12 个 Python 协议/解析单元测试，以及 empty.c 主机语法检查。

## 7. 已知边界

- 上述是软件仿真，不是新版固件的真实 ADC 端到端结果；
- SYSOSC 标称误差、VDD/VREF、ADC INL/增益/偏置、前端增益和信号源标定决定绝对准确度上限；
- 与目标信号严格相干且落在其谐波上的干扰，从单通道观测中可能不可辨识；
- 削顶、压摆率限制和过低模拟截止频率造成的信息损失无法由软件恢复；
- 赛方最终公布范围变化后，应按真实范围重跑同样的确定性矩阵和板上扫参，而不是只调一个阈值。
