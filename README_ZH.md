
## 本次改动

- **锯齿重置：**保留可行的严格周期模型；遇到空/退化区间时，检查所有可见重置是否为连续周期，再建立有界边沿偏移模型。缺失或额外跳变不自动当作合法时序。带偏移的重置附近样本不参与斜率/增益的精细拟合，返回相应不确定性诊断，不再强行套用零偏移相位区间。
- **方波准入：**去掉“边沿区域超过 20% 一律丢弃”和固定百万分惩罚。改查两侧平台、前后两半帧、覆盖周期数、有效样本数和投影信息量；边沿范围之外的误差照常计分，被排除的样本承担复杂度代价。平台不足仍拒绝。
- **背景与尖点：**用局部高阶差分 MAD 估计背景尺度并限制自动容差；源噪声包络与背景项分别处理。仅允许极少量分位数裁剪，使用保留非零尾部代价的 Huber 评分；末次拟合做稳健加权。此估计不代替真实 DC 标定，也不是噪声上界。
- **干扰自由度：**有可测背景时，禁止依赖过弱源创新能量的高阶干扰候选。该检查减少幅值分解病态，不能证明已解决所有“干扰吸收主体谐波”的实采案例。
- **带外精修：**增加截止频率、源能量、独立频带和两半帧增益一致性检查。拟合后仍检测到背景波动、边沿偏移或剩余时间不足时，不进入带外/码区间精修，保留源模型拟合结果。这是对未标定观测传递特性的保守处理。
- **截止与近整数周期：**撤销 CPU 时间放宽；检查实际经过时间，线性规划子调用按剩余预算限时。噪声回放周期保持连续估计；整数梳状谱不再直接牵动正弦载频。截止仍是协作式检查，单个不可中断的数值库调用及采集/通信耗时不由本文件硬实时保证。

可选 `SolverConfig(background_sigma=...)` 接受独立实测背景 RMS，单位与送入 `estimate` 的样本一致。默认自行估计；`observation_aperture_samples` 默认沿用诊断中使用的采样点容差。它们都不是比赛真值。

## 验证与证据边界

统计见 `VALIDATION_ZH.md`、`validation/summary.json`、针对性逐项 CSV 和保留的失败明细。`checks/test_patch.py` 使用模拟输入，包含双时钟阶梯回放、低幅值、背景波动、尖点及无效输入；可直接运行：

```bash
python checks/test_patch.py
```

两组历史模拟矩阵可复用原 8.0 包内的输入与指纹，不重复装入本补丁：

```bash
python checks/replay_matrices.py --baseline "原8.0包解压目录" --scope historical221 --output "historical221.jsonl"
python checks/replay_matrices.py --baseline "原8.0包解压目录" --scope fresh96 --output "fresh96.jsonl"
```

**本次两个上传包都没有 `samples.adc.bin` 或原始 `data.zip`。** 诊断包包含的是原始数据审计、候选追踪和历史重放结果；报告末尾明确说明未重复附上采集包。因此本次未重跑那批 365 帧，也不能确认 147 个历史失败恢复了多少。模拟输入没有被当作真实采集数据。拿到原来的 `data.zip` 后，无需整套重新采集即可重放：

```bash
python replay_raw.py --project "你的原工程目录" --data "data.zip" --output "raw-replay-8.1"
```

重放入口只读取 ZIP 内 `uart/.../samples.adc.bin`，核对原分析 SHA-256、长度和 FNV，并带入原现场标定元数据；不会生成或使用 `rt.adc.bin`。输出原始估计及频率/幅值/占空比检查；DC 与整项工程合格需沿用原测试驱动的逐项门限，脚本不会擅自补造。该入口本次只用明确标记的模拟归档验证了读取和校验流程。
